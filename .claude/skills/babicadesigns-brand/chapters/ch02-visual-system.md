# Chapter 2: Visual System — Colors, Typography & Layout

## Core Idea
Every visual decision has a single job: make the brand feel like lace on linen — refined, handmade, unhurried. The system is strict not because of rules, but because restraint is the aesthetic.

## Frameworks Introduced
- **The 5-Color Palette Rule**: Five colors, each with one assigned function. Never improvise.
  - When to use: Every design asset, every time
  - How: Start from Warm Cream (#F0E6D3) as background. Add Dark Sage (#385048) for the B mark only. Deep Charcoal (#1C1917) for all typography. Then pick ONE accent: Dusty Rose (#C4A09A) OR Sage Green (#8A9E89) — not both.

- **Max-3 Composition Rule**: Never more than 3 colors in a single composition.
  - When to use: Any designed asset — social posts, covers, documents, slides
  - How: Cream (base) + Charcoal (type) = 2. Add one accent. Stop.

- **Typography Hierarchy**: Three typefaces, three purposes — never cross-wired.
  - Cormorant Garamond Bold → hero/display headings (anything the eye should linger on)
  - Playfair Display → subheadings, section headers
  - EB Garamond → body copy, long-form reading, Substack
  - When to use: Every text element maps to exactly one tier
  - How: Never mix more than two typefaces in a single layout

## Key Concepts
- **Dark Sage Green `#385048`**: B mark color only. Also the primary dark in reversed layouts.
- **Deep Charcoal `#1C1917`**: All typography. Black is too harsh; this has warmth.
- **Warm Cream `#F0E6D3`**: "The paper everything breathes on." Background for all compositions.
- **Dusty Rose `#C4A09A`**: Tagline color + primary accent. ONE element per composition maximum.
- **Sage Green `#8A9E89`**: Labels, secondary details, nature/earth references. Never compete with Dusty Rose in same layout.
- **Cormorant Garamond Semibold**: Headings. Same font family, not Bold — per brand kit reference sheet.
- **Generous margins**: More cream than feels comfortable. White space is structure, not absence.
- **Editorial rhythm**: Short sentences, generous line-height, deliberate paragraph breaks.

## Mental Models
- "Warm golden light from upper left always" — applies to both illustration scenes and photography framing.
- Sage Green and Dusty Rose never share equal weight in one composition; one leads, one disappears.
- Layout rule: if it feels crowded, delete one element. If it still feels crowded, delete another.

## Anti-patterns
- **Warm beige / terracotta background**: That's Pinterest, not BabicADesigns. Cream (#F0E6D3) specifically, no warm tones.
- **Neon, gradients, or AI glow effects**: Antithetical to the brand. No electric blue, no gradient fills.
- **More than two accent colors in one layout**: Sage Green + Dusty Rose + anything = too much.
- **Cold blue or purple lighting**: Wrong temperature. Warm golden from upper left, always.
- **Crowded layouts**: The brand breathes. If in doubt, add white space.
- **Generic stock photos** (laptops, women smiling at screens): Not brand photography. Use illustration or own photography.

## Worked Example
**Substack cover (16:9 The Drop):**
- Background: Warm Cream
- Illustration: Scene 02 (Couch with Laptop) — protagonist in white linen + sage trousers, copper džezva on table
- Heading: "The Drop" in Cormorant Garamond Semibold, Deep Charcoal
- Date/label: Playfair Display or small caps, Sage Green
- No additional colors introduced
- Light source: upper left, warm golden

## Key Takeaways
1. Five colors, five roles — no substitution, no improvisation.
2. Max 3 colors per composition: Cream + Charcoal + one accent.
3. Cormorant for hero, Playfair for section, EB Garamond for body — never cross-wired.
4. Warm golden light from upper left in all visual scenes.
5. More white space than feels comfortable — that's the brand.
6. The tagline "The Balkanish AI Way" is always cursive script, always Dusty Rose.
